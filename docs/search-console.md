# Search Console workflow (mw4-hacks.org)

## Setup

1. Open [Google Search Console](https://search.google.com/search-console) and add the **domain** property for `mw4-hacks.org` if it is not already there.
2. Under **Sitemaps**, submit: `https://mw4-hacks.org/sitemap.xml`

## After deploy

- Re-submit sitemap when major URL or article changes ship.
- Use **URL inspection** on `/`, `/products/`, `/articles/`, and top product detail pages after launch.
